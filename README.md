# Sales & Revenue Dashboard (Power BI)

## Project Overview
This project analyzes sales and revenue data to identify trends in product performance, regional sales, and overall revenue growth. The dashboard was built in Power BI to support business decision-making.

## Tools Used
- Power BI
- Excel
- SQL

## Key Insights
- Identified top-performing products by revenue
- Analyzed monthly sales trends
- Compared revenue across regions

## Files in This Repository
- `Sales_Dashboard.pbix` – Power BI dashboard file
- `sales_data.xlsx` – source dataset

## How to View the Dashboard
1. Download the `.pbix` file from this repository
2. Open it using **Power BI Desktop**
